## About BITS
BITS is an innitiative made by Andrés Cadenas Blanco for the subject Software architecture. The main objective is to give a new aproach to the decentralized app of Lomap.
### What is a Decentralized app
We as users like to have the whole control of the data we give to companies. For this the SOLID initiative was born. It decentralize the data by giving each user a pod. This pod is fully controlled by the client whom is in charge to decide what permissions do the webapps to manage it. It's fairly new so the limitations are big but it's a fresh air for the developing environment.
## Local Installation
To install locally the project the user must have typescript and npm installed. After checking that the instructions are:

```
cd webapp
npm install
npm start
```
